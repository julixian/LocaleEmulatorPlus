# Privacy Policy / 隐私政策

Last updated: 2026-11-21

## English

**Locale Emulator Plus** is a local desktop utility for Windows.

- **No Data Collection**: Locale Emulator Plus does **not** collect, store, transmit, or share any personal information, telemetry, analytics, crash dumps, or usage data.
- **Local Storage Only**: User profiles and application settings are stored exclusively on your own device (in `%LOCALAPPDATA%\LocaleEmulatorPlus\config.toml` for the Microsoft Store version, or alongside the executable in portable mode).
- **Network Access**: The Microsoft Store version makes **no** network requests. The standalone portable edition only connects to `api.github.com` when the user manually clicks "Check for Updates".
- **Contact**: If you have any questions about this privacy policy, please open an issue at https://github.com/julixian/LocaleEmulatorPlus/issues.

## 简体中文

**Locale Emulator Plus** 是一款纯本地运行的 Windows 桌面工具。

- **不收集任何数据**：本软件不收集、不存储、不上传、不共享任何个人身份信息、遥测数据、使用统计或崩溃日志。
- **仅本地存储**：用户配置与程序专属配置文件仅保存在你的本机磁盘中（Microsoft Store 版本保存在 `%LOCALAPPDATA%\LocaleEmulatorPlus\config.toml`，便携版默认保存在程序同目录）。
- **网络行为**：Microsoft Store 版本不发起任何网络请求；独立便携版仅在用户手动点击「检查更新」时访问 `api.github.com` 查询最新版本。
- **联系方式**：如对本隐私政策有任何疑问，请前往 https://github.com/julixian/LocaleEmulatorPlus/issues 提交反馈。
